# RoeBux Brandbook v1

## Canonical identity
- Brand spelling: **RoeBux**
- Operator line: **RoeBux is operated by Essens Engineering B.V.**
- Theme base: Shopify **Horizon** v3.5.1, native-first.

## Brand essence
RoeBux is a premium hunting field-gear brand built around preparation, precision, order, reliability and modern 3D-printed craftsmanship. The launch focus is cartridge storage and practical field-ready accessories.

## Logo
- Use the supplied RoeBux logo files as source of truth.
- Use the horizontal lockup for header/footer and the stacked lockup for larger brand placements.
- Do not redraw, stretch, recolor or filter logos in code.
- A true light logo variant is required for dark hero/header use.

## Typography
- Logo: Montserrat
- Website headings: Montserrat
- Body text: Roboto

## Voice
Cinematic, premium, technical, clean, calm and adventurous. Avoid tactical, gun-bro, violent or aggressive language. RoeBux sells cartridge storage and hunting field accessories, not ammunition or firearms.

## Digital notes
- Horizon-native blocks/settings first.
- Hero 1 should be full-screen/full-viewport where practical.
- Keep content editable in Shopify theme editor.
- Do not use standalone HTML/CSS/JS, React, Vue, Next.js, Svelte, Tailwind or external frontend frameworks.
