# RoeBux Brandbook v1.1

## Canonical identity
- Brand spelling: **RoeBux**
- Operator line: **RoeBux is operated by Essens Engineering B.V.**
- Theme base: Shopify **Horizon** v3.5.1, native-first.

## Brand essence
RoeBux is a premium hunting field-gear brand built around preparation, precision, order, reliability and modern 3D-printed craftsmanship. The launch focus is cartridge storage and practical field-ready hunting accessories.

## Logo system
- Use the supplied RoeBux logo files as the source of truth.
- Use the horizontal lockup for header/navigation and compact website placements.
- Use the stacked lockup for larger brand placements, footer moments, packaging and hero/brand sections.
- Do not redraw, stretch, distort, filter or recreate logos in code.
- Do not use AI-generated logo recreations as final production assets.

### Logo color variants
- **Primary brown logo:** `#534030`  
  Use on light/off-white backgrounds.
- **Light/off-white logo:** `#FAFAF9`  
  Official light logo color for dark hero/header/footer use. This is the preferred website variant over pure white because it matches the RoeBux palette.
- **Pure white fallback:** `#FFFFFF`  
  Only use if contrast is insufficient or a platform requires pure white.
- **Orange mark/accent:** `#F47C00` with hover/deeper accent `#D35400`  
  Optional for favicon, small brand mark, highlights or UI accents. Do not use orange as the default header logo.

## Voice
Cinematic, premium, technical, clean, calm and adventurous. Avoid tactical, gun-bro, violent or aggressive language. RoeBux sells cartridge storage and hunting field accessories, not ammunition or firearms.

## Digital implementation notes
- Horizon-native blocks/settings first.
- Hero 1 should be full-screen/full-viewport where practical.
- Keep content editable in Shopify theme editor.
- Use the **light/off-white logo `#FAFAF9`** on dark transparent hero headers.
- Use the **brown logo `#534030`** on light backgrounds.
- Use orange as a deliberate premium accent, not as the dominant identity color.
- Do not use standalone HTML/CSS/JS, React, Vue, Next.js, Svelte, Tailwind or external frontend frameworks.
